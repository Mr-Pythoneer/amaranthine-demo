# Amaranthine: try the app

**Live demo: https://mr-pythoneer.github.io/amaranthine-demo/**

Amaranthine helps a grandparent with mild-to-moderate memory loss spend a few minutes a day with her own family's photos, names and stories. Her family sets it up on their own phone. She gets a calm daily visit that never marks her wrong, plus a voice companion she can ask about her family.

This site runs the real app in your browser, as two phones side by side:
- **Rose's phone:** the grandparent.
- **Anna's phone:** her daughter, who set it up.

Everything runs locally in your browser. The app's backend runs in a service worker and stores its data in your browser's IndexedDB, so nothing is uploaded anywhere.

## What's here

| Path | What it is |
|---|---|
| `index.html`, `assets/landing.*` | The landing page |
| `app/` | The app, exported for the web (React Native / Expo) |
| `sw.js` | The demo backend: the app's server, bundled to run in a service worker |
| `assets/demo-api.js` | The page's demo controls (load the demo family, start from scratch) |
| `seed/` | The fictional demo family's photos (licensed; see `seed/CREDITS.md`) |

This repository holds the built demo only. It is generated by a build script in the app's source repository. The family is fictional, and the photos are licensed stock and public-domain images.
